## 🗄️ Database Schema

The PostgreSQL database includes the following tables based on your ERD:

- **Users** - Parent/guardian information
- **Players** - Young athlete profiles
- **Coaches** - Instructor information with certifications
- **TrainingSessions** - Scheduled training sessions
- **Registrations** - Player enrollment in sessions
- **Feedback** - Session feedback and ratings
- **Franchises** - Business location management
- **Facilities** - Training facility information
- **Equipment** - Equipment tracking and management

All tables include proper relationships, foreign keys, and data validation.

## 🔧 API Endpoints

The REST API provides full CRUD operations for all entities:

### Core Endpoints
- `GET/POST/PUT/DELETE /api/users` - User management
- `GET/POST/PUT/DELETE /api/players` - Player profiles
- `GET/POST/PUT/DELETE /api/coaches` - Coach management
- `GET/POST/PUT/DELETE /api/trainingSessions` - Session scheduling
- `GET/POST/PUT/DELETE /api/registrations` - Enrollment management
